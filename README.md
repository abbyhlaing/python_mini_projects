# Python Mini Projects

A collection of beginner-friendly Python mini projects created for practice and learning purposes.

## Projects Included

### 1. Run Length Encoding
File: `run_length_encoding.py`

- Compresses repeated characters in a string
- Example:
  - Input: `aaabbc`
  - Output: `3a2b1c`

---

### 2. Employee Search System
File: `employee_search_system.py`

- Reads employee records from a CSV file
- Search employees by:
  - ID
  - Name
  - Department

Required file:
- `miniproject3.csv`

---

### 3. Music Album System
File: `music_album_system.py`

- Object-Oriented Programming (OOP) project
- Stores albums, artists, and tracklists
- Displays album information

---

### 4. Password Validator
File: `password_validator.py`

- Reads passwords from a text file
- Checks password validity rules:
  - Must start with an uppercase letter
  - Must contain at least one digit

Required file:
- `passwords.txt`

---

### 5. Animal Guessing Game
File: `animal_guessing_game.py`

- Random animal word guessing game
- Shows correct and wrong letters
- Limited attempts system

---

### 6. Capital City Quiz Game
File: `capital_city_quiz_game.py`

- Quiz game about countries and capitals
- Score tracking system
- Player name support

---

## Technologies Used

- Python 3
- CSV File Handling
- OOP Concepts
- Loops and Conditions
- File Handling
- Random Module
